# Code of conduct

Participants in LANPair's issues, pull requests and discussions should communicate respectfully, discuss technical evidence, and make it possible for others to contribute without harassment or discrimination.

Personal attacks, threats, doxxing, sexual harassment, sustained disruption and publishing another person's private information are unacceptable. Disagreement about a technical conclusion is welcome when expressed respectfully and supported by evidence.

Maintainers may remove inappropriate content, restrict participation or close discussions. Enforcement should be proportionate to the conduct and its context.

Do not publish sensitive incident reports or personal details in a public issue. For harassment on GitHub, use GitHub's abuse-reporting tools. To discuss a repository-specific incident privately, ask a maintainer for a private contact without disclosing sensitive details publicly. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
